# Simurg PTP Dark CSS Test

A standalone, local-only stylesheet that gives the Simurg forum a PTP-inspired dark appearance while preserving Simurg content and branding. The first forum topic-status column is hidden, so PTP-style read/unread topic identifiers are not shown.

## Use

1. Download `simurg-ptp-dark-local-test.css`.
2. Load it with a browser user-style extension or Safari stylesheet tool.
3. Apply it only to the Simurg domain.

## Safety

This repository is an isolated visual test. It does not modify the Simurg application, database, server, or user account.
