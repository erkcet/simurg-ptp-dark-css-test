# Simurg PTP Dark CSS Test

A standalone external stylesheet that gives Simurg a PTP-inspired dark appearance while preserving Simurg content and branding. Its desktop utility header uses two static rows, retains the native Simurg links, and does not depend on hover menus. The first forum topic-status column remains hidden, so PTP-style read/unread topic identifiers are not shown.

## Use

Use this stable external stylesheet address:

```text
https://cdn.jsdelivr.net/gh/erkcet/simurg-ptp-dark-css-test@main/simurg-ptp-dark-local-test.css
```

Load it with Simurg's External stylesheet URL setting, a browser user-style
extension, or Safari's stylesheet tool, and apply it only to the Simurg
domain. The address follows the repository's `main` branch, so it stays the
same when the stylesheet is updated.

## Safety

This repository is an isolated visual test. It does not modify the Simurg application, database, server, or user account.
